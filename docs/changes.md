- **USB (Use-Seen-Before) missed-label detection (Script 5 + master script)** — New `postannotation_scripts/5. usb_missed_labels.py` flags images likely containing an *unlabelled* instance of a class, without running a detector. Per class: collects every GT box across all splits, greedy-dedups at IoU < `--region_iou` (0.8) into fixed-pixel-location `seen_<cls>_regions` (valid for this project's fixed-camera CCTV data), pads each by 2% of **image** W/H, crops those regions from every image, drops candidates overlapping a same-class GT box in the same image, then scores them by max cosine similarity against a reference pool built from Script 2's cached embeddings (DBSCAN noise points + per cluster: centroid + `--n_farthest` farthest members). Above `--sim_thresholds` → full frame written to `missing_labels/<class>/<image>.jpg` with flagged regions in red (sim score) and existing GT boxes in green. Reuses Script 2's `compute_embeddings_for_paths` and Script 3's `auto_tune_eps`/`cluster_single_class` via `importlib` (identical math, no duplication); re-runs DBSCAN in-process rather than reading Script 3 output, which never persists per-sample cluster labels. Master script gained a run-mode select (Full EDA / Full EDA + USB / **USB only** — crops + embeds only the selected classes, skips clustering and PDF), USB prompts at Step 0, Step 5 execution after the PDF and before crop deletion, and headless args `--usb_classes`, `--usb_sim_thresholds`, `--usb_n_farthest`, `--usb_only`. Background and the failed detector-based attempts that led here: `docs/usb-missed-labels-ablation.md`.
